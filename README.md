# DR.MO Stock — ระบบสต๊อกคลินิก

แอปบนมือถือสำหรับตัดยอดและดูสต๊อกของ DR.MO CLINIC

- **หน้าแอป** (`app/`): ฝากไว้บน GitHub Pages และเปิดผ่าน LINE (LIFF) ในขั้นถัดไป
- **หลังบ้าน** (`apps-script/`): Google Apps Script ผูกกับ Google Sheet
- **ข้อมูล** (`data/drmo-stock-db.xlsx`): ฐานข้อมูลตั้งต้นที่แปลงมาจากชีต Stock clinic 2026

## โครงสร้างโฟลเดอร์

```
app/            หน้าแอป (อัปขึ้น GitHub)
  index.html
  css/style.css
  js/config.js      ← ใส่ API_URL ตรงนี้
  js/app.js
  js/demo-data.js   ข้อมูลตัวอย่าง ใช้ตอนยังไม่ได้ต่อ API
  assets/           โลโก้
apps-script/    โค้ดหลังบ้าน (คัดลอกไปวางใน Apps Script)
data/           ไฟล์ฐานข้อมูลสำหรับนำเข้า Google Sheet
tools/          สคริปต์แปลงข้อมูลจากชีตเดิม
mockup/         ตัวอย่างหน้าจอรุ่นแรก
```

## ชีตในฐานข้อมูล

| ชีต | ใช้ทำอะไร |
|---|---|
| Items | รายการสินค้า: รหัส, ชื่อ, หมวด, หน่วย, คงเหลือ, จุดสั่งซื้อ (`min_qty`), ราคา, ใช้งานอยู่ไหม (`active`) |
| Lots | ล็อตและวันหมดอายุ แต่ละล็อตมียอดคงเหลือของตัวเอง |
| Transactions | ประวัติทุกครั้ง: `OUT` เบิกออก, `IN` รับเข้า, `COUNT` นับคงเหลือ, `RETURN` คืน, `BORROW` ยืม |
| Settings | ค่าตั้ง เช่น แจ้งเตือนล่วงหน้า 90 และ 180 วัน, เวลาส่งแจ้งเตือน |
| Users | ผู้ใช้จาก LINE |

ตอนนี้ทุกคนยังแก้ข้อมูลในชีตได้เหมือนเดิม แต่อย่าเปลี่ยนชื่อชีต และอย่าเปลี่ยนแถวหัวตาราง (แถวที่ 1)

## ขั้นตอนติดตั้ง

### 1. สร้าง Google Sheet
1. เปิด Google Drive แล้วสร้าง Google Sheet ใหม่ ตั้งชื่อ `DR.MO Stock DB`
2. ไปที่ **ไฟล์ → นำเข้า → อัปโหลด** แล้วเลือก `data/drmo-stock-db.xlsx`
3. เลือก **แทนที่สเปรดชีต** แล้วกดนำเข้าข้อมูล

### 2. ใส่โค้ดหลังบ้าน
1. ในชีตนั้น ไปที่ **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ออก แล้ววางโค้ดจาก `apps-script/Code.gs` แทน กดบันทึก
3. เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้** (ครั้งแรกระบบจะขอสิทธิ์ ให้กดอนุญาต)
4. เลือกฟังก์ชัน `testSummary` แล้วกด **เรียกใช้** ใน Execution log ควรขึ้นจำนวนสินค้า 346 รายการ และ 10 หมวด

### 3. Deploy เป็น Web app
1. กด **Deploy → New deployment** แล้วเลือกประเภท **Web app**
2. ตั้ง Execute as: **Me** และ Who has access: **Anyone**
3. กด Deploy แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`
4. ทดสอบโดยเปิด `URL?action=ping` ในเบราว์เซอร์ ควรเห็น `{"ok":true,...}`

> ช่วงนี้ใครที่มีลิงก์ API ก็อ่านข้อมูลสต๊อกได้ (ยังไม่มีข้อมูลคนไข้) ขั้นต่อเชื่อม LINE จะเพิ่มการตรวจสอบผู้ใช้ด้วย LINE login

### 4. ต่อหน้าแอปกับข้อมูลจริง
เปิด `app/js/config.js` แล้วใส่ URL จากขั้นที่ 3

```js
API_URL: 'https://script.google.com/macros/s/xxxx/exec',
```

### อัปเดตโค้ดหลังบ้าน
ทุกครั้งที่ `Code.gs` เปลี่ยน ให้วางโค้ดใหม่ทับ แล้วรัน `setup` อีกครั้ง จากนั้นไปที่ **Deploy → Manage deployments → แก้ไข (รูปดินสอ) → Version: New version → Deploy** ลิงก์ `/exec` จะยังเป็นลิงก์เดิม

### 5. ขึ้น GitHub Pages
1. สร้าง repo ใหม่ใน GitHub เช่น `drmo-stock`
2. อัปโหลด **เฉพาะไฟล์ในโฟลเดอร์ `app/`** และไฟล์ `apps-script/`, `README.md`, `.gitignore`
3. ไปที่ **Settings → Pages** แล้วตั้ง Source เป็น branch `main`
4. เปิดแอปที่ `https://<ชื่อผู้ใช้>.github.io/drmo-stock/app/`

> **ห้ามอัปไฟล์ Excel ของคลินิก (`*.xlsx`) รูปภาพ หรือโฟลเดอร์ `data/`** เพราะ GitHub Pages แบบฟรีเปิดให้ทุกคนดูได้
> ไฟล์ `.gitignore` กันไว้ให้แล้วถ้าใช้คำสั่ง git หรือ GitHub Desktop
> แต่ถ้าลากไฟล์ขึ้นหน้าเว็บ GitHub เอง ต้องเลือกไฟล์เองให้ถูก
